El DOM y los eventos

Acá se junta todo. En el librito anterior aprendiste JavaScript; ahora lo usás para tocar la página: cambiar textos, mostrar y ocultar cosas, y reaccionar cuando el usuario hace clic. Esto es lo que hace que una página sea interactiva de verdad.

Cómo estudiarlo

Necesitás un index.html con contenido y un script.js enlazado. Cada ejemplo modifica esa página. Abrí la consola para ver errores. Flechas ← → para navegar.

Capítulo 1

Qué es el DOM

Cuando el navegador lee tu HTML, arma una representación viva de la página en memoria: el DOM (Document Object Model). Es tu HTML convertido en objetos que JavaScript puede leer y modificar.

El HTML como árbol

El DOM es una estructura de árbol que refleja el anidamiento de tu HTML:

document
  └─ html
      └─ body
          ├─ h1
          └─ button

JavaScript accede a ese árbol a través de document, el punto de entrada a toda la página. Desde ahí podés buscar cualquier elemento, cambiarlo, o agregar nuevos.

La idea clave

El HTML es el estado inicial de la página. El DOM es la página viva, y JavaScript la modifica en tiempo real. Cuando hacés clic en un botón y aparece un mensaje, lo que pasó es que JS modificó el DOM. Toda interactividad es, en el fondo, modificar el DOM.

HTML vs DOM

El HTML es lo que escribiste en el archivo. El DOM es lo que hay en memoria ahora mismo, que pudo cambiar por JavaScript. Si inspeccionás con DevTools, ves el DOM actual, que puede diferir del HTML original.

Capítulo 2

Seleccionar elementos

Antes de modificar algo, tenés que agarrarlo. JavaScript busca elementos en el DOM usando los mismos selectores del CSS que ya conocés.

querySelector: el que vas a usar siempre

javascript
const titulo = document.querySelector("h1");        // por etiqueta
const caja   = document.querySelector(".tarjeta");  // por clase
const menu   = document.querySelector("#menu");     // por id

querySelector devuelve el primer elemento que coincide, usando sintaxis de CSS (con el punto para clases, el numeral para ids). Es el más versátil.

Seleccionar varios

javascript
const botones = document.querySelectorAll(".boton");   // todos los .boton

botones.forEach((boton) => {
  console.log(boton);   // recorrer con forEach, como un array
});
Si sale null...

Si querySelector devuelve null, no encontró el elemento. Causas típicas: el selector está mal escrito, o el <script> corre antes de que el HTML exista. Por eso el script va al final del <body> (librito 1): así el HTML ya está cargado cuando el JS busca.

Capítulo 3

Modificar elementos

Con el elemento agarrado, ya podés cambiarlo: su texto, sus clases, sus estilos, sus atributos. Esto es la mitad de la interactividad.

Cambiar el texto

javascript
const titulo = document.querySelector("h1");
titulo.textContent = "Nuevo título";   // cambia el texto
textContent vs innerHTML

textContent pone texto puro (seguro). innerHTML interpreta HTML, y es peligroso con datos del usuario (abre la puerta al XSS que viste en seguridad). Usá textContent salvo que de verdad necesites insertar HTML propio y confiable.

Cambiar clases (lo más útil)

En vez de escribir estilos desde JS, la mejor práctica es tener las clases en el CSS y agregarlas o quitarlas desde JavaScript:

javascript
const caja = document.querySelector(".tarjeta");
caja.classList.add("activa");      // agregar clase
caja.classList.remove("activa");   // quitar
caja.classList.toggle("activa");   // si está la saca, si no la pone

toggle es oro: con una línea prendés y apagás un estado (un menú abierto, un modo oscuro, una tarjeta seleccionada). El estilo vive en el CSS; JS solo pone o saca la clase.

Cambiar estilos y atributos directamente

javascript
caja.style.display = "none";              // ocultar
imagen.setAttribute("src", "otra.jpg");   // cambiar un atributo
input.value = "";                         // vaciar un campo
Capítulo 4

Eventos: reaccionar al usuario

Un evento es algo que pasa: un clic, una tecla, mover el mouse, enviar un formulario. Con eventos, tu página reacciona a lo que hace la persona. Es la otra mitad de la interactividad.

addEventListener

Le decís a un elemento "cuando pase esto, ejecutá esta función":

javascript
const boton = document.querySelector("#comprar");

boton.addEventListener("click", () => {
  console.log("¡Hicieron clic!");
});

Se lee: "en el botón, escuchá el evento click, y cuando ocurra, ejecutá esta función". La función que se pasa se llama callback: corre cuando el evento sucede, no antes.

Los eventos más comunes

EventoCuándo ocurre
clickAl hacer clic en el elemento.
inputAl escribir en un campo (en cada tecla).
submitAl enviar un formulario.
keydownAl presionar una tecla.
mouseoverAl pasar el mouse por encima.

Ejemplo: un botón que muestra y oculta

javascript
const boton = document.querySelector("#toggle");
const menu = document.querySelector("#menu");

boton.addEventListener("click", () => {
  menu.classList.toggle("oculto");   // prende/apaga la clase que lo esconde
});

Combinás lo del capítulo anterior (toggle) con un evento (click): con seis líneas hiciste un menú que se abre y cierra. Ese patrón, evento + cambiar clase, es la base de casi toda la interactividad.

Capítulo 5

El objeto event

Cuando un evento ocurre, JavaScript le pasa a tu función un objeto con información sobre lo que pasó. Sirve para saber qué elemento se tocó y para controlar el comportamiento por defecto.

Recibir el evento

javascript
boton.addEventListener("click", (event) => {
  console.log(event.target);   // el elemento que disparó el evento
});

event.target es el elemento concreto sobre el que ocurrió. Útil cuando el mismo manejador cubre varios elementos.

preventDefault: frenar lo automático

Algunos elementos tienen comportamiento por defecto: un formulario, al enviarse, recarga la página. Casi siempre querés evitar eso para manejarlo con JavaScript:

javascript
const formulario = document.querySelector("form");

formulario.addEventListener("submit", (event) => {
  event.preventDefault();   // NO recargar la página
  console.log("Formulario enviado, lo manejo yo");
});

Leer el valor de un campo

javascript
const input = document.querySelector("#email");

input.addEventListener("input", (event) => {
  console.log(event.target.value);   // lo que hay escrito, en vivo
});

El .value de un input es lo que el usuario escribió. Con el evento input lo leés en cada tecla; esto es la base de la validación en vivo, tema del próximo librito.

Capítulo 6

Crear elementos desde JavaScript

Hasta ahora modificaste elementos que ya existían. También podés crear nuevos y agregarlos a la página. Es como se muestran listas de datos: una tarjeta por cada producto, un ítem por cada tarea.

Crear y agregar

javascript
const lista = document.querySelector("#lista");

const item = document.createElement("li");   // crear un <li>
item.textContent = "Nueva tarea";            // ponerle texto
lista.append(item);                          // agregarlo a la lista

El patrón estrella: renderizar un array

Acá se junta todo el track: tenés datos (un array de objetos, del librito de JS) y generás un elemento HTML por cada uno.

javascript
const productos = [
  { nombre: "Teclado", precio: 25000 },
  { nombre: "Mouse", precio: 12000 }
];

const contenedor = document.querySelector("#productos");

productos.forEach((producto) => {
  const tarjeta = document.createElement("div");
  tarjeta.classList.add("tarjeta");
  tarjeta.textContent = `${producto.nombre}: $${producto.precio}`;
  contenedor.append(tarjeta);
});

Recorrés el array con forEach, creás una tarjeta por producto, y la agregás. Así funciona toda tienda, todo listado, todo feed que ves en la web: datos que se convierten en elementos.

Todo el track en un ejemplo

Ese bloque usa arrays y objetos (librito 6), forEach, template strings, y manipulación del DOM. Cuando lo entendés, entendés cómo se construye la mayoría del frontend.

Capítulo 7

Ejemplo completo: un contador de tareas

Juntemos selección, eventos, creación de elementos y datos en algo que funciona: agregar tareas a una lista escribiendo en un campo.

html
<input id="campo" placeholder="Nueva tarea">
<button id="agregar">Agregar</button>
<ul id="lista"></ul>
script.js
const campo = document.querySelector("#campo");
const boton = document.querySelector("#agregar");
const lista = document.querySelector("#lista");

boton.addEventListener("click", () => {
  const texto = campo.value.trim();     // lo escrito, sin espacios sobrantes
  if (texto === "") return;             // si está vacío, no hacer nada

  const item = document.createElement("li");
  item.textContent = texto;
  lista.append(item);                   // agregar a la lista

  campo.value = "";                     // limpiar el campo
  campo.focus();                        // volver a enfocarlo
});

Qué hace, paso a paso

  1. Agarra los tres elementos con querySelector.
  2. Escucha el clic en el botón.
  3. Lee lo escrito; si está vacío, corta con return.
  4. Crea un <li>, le pone el texto, lo agrega a la lista.
  5. Limpia el campo y lo vuelve a enfocar para seguir escribiendo.

Con menos de 15 líneas hiciste una función real. Todo lo del track está acá: selección, eventos, condicionales, creación de elementos.

Cheatsheet y glosario

Cheatsheet

DOM y eventos
// seleccionar
document.querySelector(".clase")        // el primero
document.querySelectorAll(".clase")     // todos (forEach)

// modificar
el.textContent = "texto"                // texto (seguro)
el.classList.add / remove / toggle("x") // clases
el.style.display = "none"               // estilo directo
el.setAttribute("src", "...")           // atributo
input.value                             // valor de un campo

// eventos
el.addEventListener("click", (event) => { ... })
event.target                            // el elemento tocado
event.preventDefault()                  // frenar lo automático

// crear
const nuevo = document.createElement("div")
contenedor.append(nuevo)

Glosario

TérminoQué es
DOMLa página viva en memoria, como árbol de objetos, que JS modifica.
querySelectorBuscar un elemento con sintaxis de CSS.
textContentLeer o cambiar el texto de un elemento (seguro).
classListAgregar, quitar o alternar clases.
EventoAlgo que pasa (clic, tecla, submit) a lo que podés reaccionar.
addEventListenerRegistrar una función que corre cuando ocurre un evento.
callbackLa función que se ejecuta cuando el evento sucede.
preventDefaultCancelar el comportamiento por defecto (recargar, seguir un link).
Lo que te llevás

Sabés seleccionar elementos, modificarlos, reaccionar a eventos y crear contenido nuevo. Ya podés hacer páginas interactivas de verdad. En el próximo librito aplicás esto a los formularios: capturar datos y validarlos con feedback al usuario.
