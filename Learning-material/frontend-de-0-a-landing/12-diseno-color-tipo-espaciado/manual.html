Diseño: color, tipografía y espaciado

Sabés maquetar, pero ¿cómo hacés que se vea bien? El diseño no es magia ni talento innato: son unas pocas decisiones sistemáticas sobre color, tipografía y espacio. Este librito te da un método para que tus páginas se vean profesionales, y te enseña a organizar esas decisiones con design tokens.

Cómo estudiarlo

Aplicá cada idea a una página tuya. El diseño mejora comparando: probá dos opciones y quedate con la mejor. Flechas ← → para navegar.

Capítulo 1

Jerarquía visual: guiar el ojo

El principio que sostiene todo el diseño: no todo es igual de importante, y el diseño tiene que mostrarlo. La jerarquía visual guía el ojo hacia lo que importa, en orden.

Qué la crea

  • Tamaño: lo más grande se ve primero. Un título grande, un botón generoso.
  • Color y contraste: lo que contrasta más, resalta. El CTA en color de acento sobre un fondo neutro.
  • Espacio: lo que tiene aire alrededor se destaca. El espacio en blanco no es vacío desperdiciado, es foco.
  • Posición: lo de arriba y a la izquierda se lee primero (en nuestra cultura).

El test del entrecerrar los ojos

Mirá tu página entrecerrando los ojos hasta que se vea borrosa. Lo que igual se destaca es lo que tiene jerarquía. Si todo se ve igual de importante (o nada resalta), falta jerarquía. Es una prueba rápida y sorprendentemente útil.

El error del principiante

Hacer todo grande, colorido y llamativo. Si todo grita, nada se escucha. El buen diseño elige qué destacar y deja el resto tranquilo. El contraste necesita calma alrededor para funcionar.

Capítulo 2

Color: armar una paleta

Elegir colores al azar es la forma más rápida de que algo se vea amateur. Una paleta se arma con roles, no con "colores lindos sueltos".

Los roles de una paleta

RolPara qué
NeutrosLa mayor parte: fondos, textos, bordes. Grises, blancos, casi-negros. El 80% de la página.
Primario / acentoUn color de marca para lo importante: botones, enlaces, destacados. Usado con moderación.
SemánticosVerde para éxito, rojo para error, amarillo para aviso. Comunican estado.

La regla de la proporción

Una guía clásica: 60% neutro, 30% un color secundario, 10% acento. El acento es escaso justamente para que resalte. Si pintás todo del color de marca, el CTA deja de destacarse.

De dónde sacar buenas paletas

No la inventes de cero. Herramientas como Coolors, o las paletas de sistemas de diseño (como los colores de Tailwind), te dan combinaciones que funcionan. Elegí un color de marca y generá sus variantes (más claro, más oscuro) alrededor.

Contraste, siempre

Recordá del librito de accesibilidad: el texto tiene que contrastar con su fondo (mínimo 4.5:1). Una paleta puede ser hermosa y aun así ilegible. Verificá el contraste de tus combinaciones de texto.

Capítulo 3

Tipografía en el diseño

Ya viste las propiedades tipográficas en CSS. Acá va la parte de diseño: cómo elegir y combinar fuentes, y cómo crear una escala de tamaños que se vea armónica.

Elegir fuentes

  • Una sola fuente bien usada alcanza para la mayoría de los proyectos. Distintos pesos y tamaños de la misma familia dan variedad sin desorden.
  • Si combinás dos, que contrasten: una para títulos (con más personalidad) y otra para texto (muy legible). No dos parecidas, que se ven como un error.
  • Legibilidad primero en el texto de lectura. Las fuentes decorativas, solo para títulos y con cuidado.

La escala tipográfica

No elijas tamaños al azar (16px, 19px, 23px...). Usá una escala: cada tamaño es el anterior multiplicado por un factor constante. Eso crea armonía visual.

css · una escala simple
--texto-sm:   0.875rem;  /* 14px */
--texto-base: 1rem;      /* 16px */
--texto-lg:   1.25rem;   /* 20px */
--texto-xl:   1.5rem;    /* 24px */
--texto-2xl:  2rem;      /* 32px */
--texto-3xl:  3rem;      /* 48px */

Con seis tamaños definidos cubrís toda una página, y todo se ve proporcionado porque los saltos son consistentes. Esas variables son un adelanto de los design tokens, dos capítulos más adelante.

Capítulo 4

Espaciado: el arma secreta

Lo que más separa un diseño amateur de uno profesional no es el color ni la fuente: es el espacio. Un buen uso del espaciado hace que cualquier cosa se vea prolija y respirada.

Una escala de espaciado

Igual que con la tipografía, no uses valores al azar (7px acá, 13px allá). Definí una escala y usá solo esos valores en toda la página:

css · escala de espaciado
--sp-1:  0.25rem;  /* 4px */
--sp-2:  0.5rem;   /* 8px */
--sp-3:  1rem;     /* 16px */
--sp-4:  1.5rem;   /* 24px */
--sp-5:  2rem;     /* 32px */
--sp-6:  3rem;     /* 48px */
--sp-7:  5rem;     /* 80px */

Todos los paddings, margins y gaps salen de esta escala. El resultado es un ritmo visual consistente: los espacios "riman" entre sí.

Más aire del que creés

El error más común es apretar todo. Dale espacio a los elementos: padding generoso en las secciones, separación clara entre bloques, aire alrededor de lo importante. El espacio en blanco transmite calidad y hace todo más fácil de leer.

La prueba práctica

Cuando algo "se ve amateur" pero no sabés por qué, casi siempre es falta de espacio. Duplicá los paddings y márgenes de las secciones y mirá cómo mejora. El espacio es gratis y rinde muchísimo.

Capítulo 5

Design tokens: tus decisiones en variables

Ya viste escalas de color, tipografía y espaciado. Los design tokens son esas decisiones guardadas como variables de CSS, para usarlas en toda la página de forma consistente y cambiarlas en un solo lugar.

Variables CSS

Se definen una vez, normalmente en :root (la raíz del documento), y se usan en todo el CSS con var():

css
:root {
  /* colores */
  --color-texto: #1a2230;
  --color-fondo: #ffffff;
  --color-acento: #0e7c86;

  /* tipografía */
  --texto-base: 1rem;
  --texto-2xl: 2rem;

  /* espaciado */
  --sp-3: 1rem;
  --sp-5: 2rem;

  /* otros */
  --radio: 12px;
  --sombra: 0 4px 12px rgba(0,0,0,0.1);
}
css · usarlos
body {
  color: var(--color-texto);
  background: var(--color-fondo);
}
.boton {
  background: var(--color-acento);
  padding: var(--sp-3) var(--sp-5);
  border-radius: var(--radio);
}

Por qué cambian todo

  • Consistencia: todos usan los mismos valores. No hay diez tonos de azul ligeramente distintos.
  • Cambios en un lugar: ¿querés cambiar el color de marca? Tocás una variable y se actualiza toda la página.
  • Temas: un modo oscuro es, en el fondo, redefinir estas variables. Cambiás los valores y toda la página cambia.
Así está hecho este libro

Los colores, tipografías y espaciados de estos manuales son todos design tokens en :root. Por eso el tema claro/oscuro funciona cambiando solo las variables. Es exactamente esta técnica.

Capítulo 6

Componentes consistentes

Una página se ve profesional cuando sus piezas repetidas (botones, tarjetas, campos) son consistentes entre sí. Con tus tokens, definir esas piezas una vez es fácil.

Un botón, bien hecho

css
.boton {
  background: var(--color-acento);
  color: white;
  padding: var(--sp-3) var(--sp-5);
  border: none;
  border-radius: var(--radio);
  font-size: var(--texto-base);
  font-weight: 600;
  cursor: pointer;
  transition: background 0.2s;
}
.boton:hover { background: #0a5c63; }

Ese botón usa los tokens de color, espaciado y radio. Todos los botones de la página comparten esta clase, así que se ven idénticos. Cambiás la clase y cambian todos.

Una tarjeta, bien hecha

css
.tarjeta {
  background: var(--color-fondo);
  padding: var(--sp-5);
  border-radius: var(--radio);
  box-shadow: var(--sombra);
}
El poder de reutilizar

Definir .boton y .tarjeta una vez, con tokens, y reusarlas en toda la página es lo que hace que se vea coherente. Es un mini sistema de diseño, la misma idea que usan las empresas a gran escala.

Cierre

Cheatsheet y glosario

El método en 5 pasos

  1. Definí una paleta con roles (neutros, acento, semánticos), proporción 60/30/10.
  2. Elegí una o dos fuentes y una escala tipográfica.
  3. Definí una escala de espaciado y usá solo esos valores.
  4. Guardá todo como design tokens (variables CSS en :root).
  5. Construí componentes (botón, tarjeta) con esos tokens y reutilizalos.

Cheatsheet
