# Frontend, de 0 a una landing page

Un track de la colección: 14 libritos que te llevan desde no saber qué es el HTML hasta construir y publicar una landing page real. Cada librito es un `manual.html` navegable (mismo estilo que el resto de la colección), y los que tienen código traen su carpeta `ejemplos/`.

## El recorrido

Bases de la web → maquetado con HTML/CSS → interactividad con JavaScript → calidad → **proyecto: la landing** → online.

## Libritos

| # | Librito | De qué va |
|---|---------|-----------|
| 01 | [Cómo funciona la web](01-como-funciona-la-web/) | Cliente/servidor, el navegador, y los 3 roles: HTML, CSS, JS |
| 02 | [HTML: estructura y semántica](02-html-estructura-semantica/) | Etiquetas, jerarquía, HTML semántico, buenas prácticas |
| 03 | [CSS: fundamentos](03-css-fundamentos/) | Selectores, cascada, box model, colores, unidades, tipografía |
| 04 | [Layout: Flexbox y Grid](04-css-layout-flexbox-grid/) | Los dos sistemas de maquetado modernos y cuándo usar cada uno |
| 05 | [Responsive design](05-responsive-design/) | Mobile-first, media queries, unidades relativas, imágenes fluidas |
| 06 | [JavaScript de 0](06-javascript-de-0/) | Variables, tipos, funciones, arrays, objetos, control de flujo |
| 07 | [El DOM y eventos](07-dom-y-eventos/) | Seleccionar y modificar la página, escuchar eventos |
| 08 | [Formularios y validación](08-formularios-y-validacion/) | Capturar datos, validar en el navegador, dar feedback |
| 09 | [Accesibilidad y SEO](09-accesibilidad-y-seo/) | HTML accesible, contraste, metadatos básicos |
| 10 | [Rendimiento](10-rendimiento/) | Optimizar imágenes y fuentes, por qué importa la velocidad |
| 11 | [Anatomía de una landing](11-anatomia-de-una-landing/) | Las secciones: hero, beneficios, prueba social, CTA, footer |
| 12 | [Diseño: color, tipo, espaciado](12-diseno-color-tipo-espaciado/) | Paleta, tipografías, escala de espaciado, design tokens |
| 13 | [Proyecto: la landing page](13-proyecto-landing-page/) | Construirla completa, HTML + CSS + JS, código real y funcional |
| 14 | [Deploy de la landing](14-deploy-de-la-landing/) | Publicarla gratis en GitHub Pages o Netlify |

## Cómo estudiarlo

En orden. Cada librito se apoya en el anterior, y el 13 (el proyecto) usa todo lo aprendido para construir una landing que funciona de verdad. El 14 la deja online.

## Formato de cada librito

```
NN-tema/
  manual.html        el libro navegable
  ejemplos/          código de ejemplo (en los que aplica)
```
