# INTRO · Python de 0, el libro

El punto de partida de toda la colección y un libro de Python completo por sí mismo. Para quien nunca programó: de "qué es programar" a escribir programas con objetos, manejar errores, leer archivos, y conectar Python con una página web y una base de datos. Todo en Python, con muchísimos ejemplos resueltos paso a paso y probados de verdad.

## Qué hay acá
- `manual.html` — **54 capítulos en 12 partes**:
  1. **Primeros pasos:** qué es programar, cómo correr Python, print y la consola, comentarios y estilo.
  2. **Datos y variables:** variables, números, texto (strings), booleanos, conversión de tipos e input.
  3. **Control de flujo:** condicionales, condiciones compuestas, bucles for y while, break/continue y patrones.
  4. **Estructuras de datos:** listas, tuplas, diccionarios, sets, estructuras anidadas.
  5. **Funciones:** lo básico, parámetros y retorno a fondo, ámbito y buenas prácticas.
  6. **Objetos (POO):** clases y objetos, métodos y estado, objetos que interactúan, herencia.
  7. **Robustez:** errores y excepciones, archivos, módulos.
  8. **Ejercicios resueltos** (dificultad creciente): cómo pensar un problema, ejercicios fáciles, pedido con 25% off, descuentos escalonados, dos pedidos y el stock, carrito con POO, proyecto calculadora, proyecto gestor de stock.
  9. **Python en la web:** cliente/servidor, generar HTML (div, listas), base de datos (CRUD), y un flujo completo.
  10. **Repaso** de lo esencial.
  11. **Herramientas del día a día:** list comprehensions y zip, fechas y horas (datetime), JSON, anotaciones de tipo (type hints), depurar errores, y cómo organizar un programa (módulos, pip, entornos).
  12. **Más proyectos:** el juego de adivinar el número, una lista de tareas que se guarda (JSON), y un análisis de ventas desde datos, más el cierre final.
- `ejemplos/` — 28 scripts ejecutables, uno por tema, todos probados.
- `ejemplos/salidas/` — la salida real de cada script.

## Probar
```
python3 ejemplos/01_fundamentos.py
python3 ejemplos/e_gestor.py
```
Todo usa Python puro (sqlite viene incluido). No hace falta instalar nada extra.
