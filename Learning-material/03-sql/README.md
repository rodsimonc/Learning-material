# 03 · Bases de datos y SQL

De qué es una tabla a joins, agrupaciones e índices, con SQL corrido contra una base real (SQLite).

## Qué hay acá
- `manual.html` — 13 capítulos: fundamentos, consultas de verdad, que ande bien (índices, transacciones, SQL desde el código), y a producción.
- `ejemplos/run.py` — crea la base de ejemplo y corre todas las consultas del libro. Corré: `python run.py`.
- `ejemplos/salidas/` — la salida real de cada consulta, incluido el EXPLAIN mostrando SCAN vs índice.
