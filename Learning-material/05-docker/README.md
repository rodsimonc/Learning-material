# 05 · Docker y deploy

De "¿qué es un contenedor?" a subir una imagen y desplegarla.

## Qué hay acá
- `manual.html` — 11 capítulos: fundamentos, construir imágenes (Python y Node), correr y orquestar con Compose, y a producción.
- `ejemplos/` — Dockerfiles listos para `app-python` y `app-node`, un `Dockerfile.multistage`, y un `docker-compose.yml` (app + Postgres).

## Nota
Los ejemplos están listos para correr con `docker build` / `docker compose up`. Las salidas de consola del libro son ilustrativas (correr Docker necesita un daemon).
