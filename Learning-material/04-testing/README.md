# 04 · Testing

De no haber escrito un test a cubrir una función con pytest y jest.

## Qué hay acá
- `manual.html` — 12 capítulos: fundamentos, pytest y jest, mocks, integración y cobertura.
- `ejemplos/` — el mismo código en Python y Node (`carrito.py` / `carrito.js`) con sus tests.
- `ejemplos/salidas/` — corridas reales: pytest, jest, cobertura, y un test fallando a propósito.

## Correr
- Python: `pip install pytest pytest-cov` y `pytest -v`
- Node: `npm install` y `npx jest`
