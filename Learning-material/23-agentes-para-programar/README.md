# 23 · Agentes para programación

Cómo programar con agentes de IA (Cursor, Claude Code, Copilot, Windsurf) con criterio: dirigir, dar contexto, revisar y saber qué no delegar. Práctico, sin código ejecutable: es la forma de trabajar.

## Qué hay acá
- `manual.html` — 10 capítulos: de autocompletar a agente, el panorama de herramientas, el contexto lo es todo, escribir buenos prompts para código, revisar el código (la habilidad clave), el flujo de trabajo con agente (+ Git como red), MCP (darle capacidades), límites y riesgos (qué no delegar), y checklist.

Idea de fondo: los agentes son un multiplicador de lo que ya sabés, no un reemplazo. Por eso el resto de la colección es lo que te deja usarlos bien.
