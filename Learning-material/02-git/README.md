# 02 · Git y control de versiones

De "no sé qué es un commit" a manejar ramas, conflictos y flujo de equipo con Pull Requests.

## Qué hay acá
- `manual.html` — el libro completo, navegable. 13 capítulos en 4 partes: fundamentos, ramas y colaboración, GitHub, y rescate.
- `ejemplos/demo.sh` — reproduce la demo del libro paso a paso en un repo de juguete.
- `ejemplos/salidas/` — la salida real capturada de cada comando (init, commit, diff, merge, conflicto, stash).

Todo lo marcado como "salida real" en el libro se ejecutó de verdad.
