# 21 · AWS, el mapa conceptual (teórico)

Librito teórico: no hay código ejecutable. El objetivo es el modelo mental de AWS, para no ahogarte cuando abras la consola. Cada servicio atado a algo que ya sabés de la colección.

## Qué hay acá
- `manual.html` — 10 capítulos: qué es AWS y el modelo de la nube (regiones, zonas), cómputo (EC2, ECS/Fargate, Lambda), datos (S3, RDS, DynamoDB), red y entrega (VPC, CloudFront, Route 53), seguridad (IAM y menor privilegio), cómo se mapea la tienda a AWS, el modelo de precios (y cómo no asustarte), AWS vs PaaS (cuándo cada uno), y glosario.

Es conceptual por diseño: AWS tiene 200+ servicios y una curva empinada; con el mapa puesto, los tutoriales concretos después se siguen fácil.
